# Камера в редакторе стены (без нейросетей)

## Быстрый запуск на ПК

Открой PowerShell **в корне этой папки** и выполни:

```powershell
py -3.12 -m http.server 8000 --bind 127.0.0.1
```

Открой `http://localhost:8000/wall-lab/`, затем нажми **Включить камеру**.
Python-зависимости и `uvicorn` не нужны: это статический интерфейс на Three.js.

## Телефон (Android / iPhone)

Для доступа к камере страница должна открываться по HTTPS. Адрес вида `http://192.168.1.100:8000/wall-lab/` не считается безопасным и обычно блокирует getUserMedia.

Самый простой вариант без серверного API — загрузить `wall-lab/` с остальной структурой проекта на существующий GitHub Pages и открыть:

https://xintes.github.io/webar-ruins/wall-lab/

Это будет работать только **после загрузки новых файлов в репозиторий и публикации Pages**.

Альтернатива — временный HTTPS-туннель: запусти Python http.server и `cloudflared tunnel --url http://localhost:8000`, открой выданный временный HTTPS-адрес + `/wall-lab/`. Этот туннель публичен — не используй его для конфиденциальных данных.

## Что реально умеет этот этап

- Живая задняя камера телефона и отображение 3D-стены поверх изображения.
- Ручная подгонка: позиция, размеры, поворот, материал.
- Экспорт GLB и настроек JSON.
- Снимок PNG из браузера.

## Чего пока НЕТ

- Автоматического распознавания башни в кадре.
- Камерной калибровки и привязки в метрах.
- Стабильного положения стены при перемещении телефона.
- Автоматической маски перекрытий: она отключается в режиме камеры, потому что ручная маска относится только к эталонной фотографии.

Следующий этап — вычисление позы камеры на серверном OpenCV на основе заранее подготовленных реальных ориентиров. Иначе виртуальная стена просто остаётся на одном месте экрана.
