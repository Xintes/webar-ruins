Добавление ракурса в OpenCV

Здесь ты показываешь программе, что именно нужно узнавать. Опорная фотография должна содержать много характерных деталей сооружения. Рядом с ней — прозрачное PNG-наложение стены, выставленное именно под эту фотографию. Система сопоставляет их автоматически при наведении камеры.

Мышью выдели на фотографии башню или узнаваемую часть фасада — по этим деталям OpenCV будет узнавать место:

Область ещё не выделена. По умолчанию будет применена область зоны.

Эта операция по умолчанию доступна только с localhost на ПК, где запущен OpenCV.

Быстрый путь: открой редактор стены, подгони конструкцию к своему фото и нажми «Экспорт прозрачной стены». Если фото исходное — просто используй эталон из редактора. Добавленные ракурсы кешируются сервером автоматически, перезапуск не требуется.

При добавлении следующего ракурса стена должна быть подготовлена под его перспективу. Это не «обучение нейросети», а построение набора эталонов для локализации по особенностям снимка.
