Наведите камеру на башню
Проверяем подключение к серверу OpenCV…

Распознавание: камера отправляет отдельные кадры в OpenCV API. При задержке облачного ответа браузер временно удерживает найденную стену и приблизительно компенсирует небольшие сдвиги кадра.

Сервер сопоставляет естественные детали башни с эталонной фотографией. Стена перемещается по найденной перспективе. Это первый режим для ограниченной зоны обзора, пока без метрической 3D-позы и корректного параллакса при обходе башни.

Подключение API на телефоне

На компьютере с локальным сервером оставь поле пустым. Для GitHub Pages нужен отдельный HTTPS-сервер; обычный HTTP-адрес локального ПК браузер блокирует.
