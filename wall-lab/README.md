# Wall Photo Lab — быстрый макет стены на фотографии

Это самостоятельный редактор для ОДНОГО контрольного ракурса. Не нужен Blender или нейросети. Он использует THREE.WebGLRenderer и настоящую 3D-геометрию стены. Текущие размеры условные.

1. Запустите прежний OpenCV-сервер в папке `server`:

   `..\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000`

2. Откройте `http://localhost:8000/wall-lab/`.
3. Перетаскивайте жёлтую точку: это основание стыка стены с башней.
4. Меняйте длину, высоту, угол ухода, глубину, толщину и яркость. Редактор сам запоминает настройки в браузере.
5. Для обсуждения нажмите `Сохранить макет PNG`. Для продолжения — `Скачать настройки JSON` и `Экспортировать стену GLB`.

## Важно

- У башни по фотографии на левом крае стоит стена **как гипотетический вариант** — без утверждения об историческом облике. Для реальной реставрации понадобятся источники и замеры.
- Фото содержит столбы, машины, людей, забор. Они не полностью маскируются. Маска башни ручная и работает **только на этой фотографии**.
- Контрольный снимок не содержит сведений о фокусном расстоянии, дистанции до башни и точной геометрии. Поэтому единицы геометрии условны, а совпадение на фото не подтверждает совпадение на месте.
- Экспорт GLB **не включает смещение в пикселях фотографии**. Начало модели = основание стыка стены с башней. Данные положения и параметры виртуальной камеры содержатся в JSON.
- Экспорт GLB содержит динамически созданную кирпичную текстуру. Её оттенки — демонстрационные, не фотограмметрия.
- Сайт загружает Three.js с CDN и требует подключения к Интернету при первом открытии.

Следующий шаг для реального AR: измерить опорную геометрию, получить параметры камеры и решить задачу PnP через OpenCV. Согласованный GLB после этого сможет отображаться через Three.js, но текущий Photo Lab — **не готовая AR-привязка**.
