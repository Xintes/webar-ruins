# WebAR — реконструкция руин (первый прототип)

Статический сайт на MindAR 1.2.5 + Three.js 0.160.0. Ничего собирать npm не нужно.

## Быстрый запуск

1. Откройте репозиторий GitHub, создайте публичный репозиторий и загрузите эти файлы в корень.
2. В Settings -> Pages выберите Deploy from a branch, `main`, `/(root)`, Save.
3. Откройте выданный `https://...github.io/.../` адрес на телефоне, нажмите «Включить AR».
4. Направьте телефон на *официальное тестовое изображение MindAR*, открытое на другом экране:
   https://cdn.jsdelivr.net/gh/hiukim/mind-ar-js@1.2.5/examples/image-tracking/assets/card-example/card.png
5. На изображении появится тестовый макет постройки.

Для просмотра на ПК достаточно `python -m http.server 8000`, затем открыть `http://localhost:8000` (с веб-камерой). Нельзя открыть файл `index.html` двойным щелчком. Для камеры на другом устройстве нужен HTTPS, просто `http://192.168...` обычно не подходит.

## Подмена на настоящую башню

1. Снимите фотографию **сохранившейся части** башни со стабильными уникальными деталями. Для MindAR лучше большой почти плоский участок фасада, без сильной перспективы, деревьев и бликов.
2. Скомпилируйте фотографию в `.mind` на https://hiukim.github.io/mind-ar-js-doc/tools/compile
3. Положите скачанный файл в `assets/targets.mind`.
4. В Blender экспортируйте полную реконструкцию: File -> Export -> glTF 2.0, Format `glTF Binary (.glb)`.
5. Положите модель в `assets/building.glb`.
6. В `settings.js` поменяйте:
   `targetFile: "./assets/targets.mind"` и `modelFile: "./assets/building.glb"`.
7. На телефоне откройте сайт с `?edit=1` на конце адреса. Изменяйте положение, масштаб и углы. Нажмите «Скопировать настройки» и замените объект `transform` в `settings.js` скопированными значениями. При обычном посещении без `?edit=1` посетители не видят панель калибровки.

## Система координат

Локальная система привязана к **плоскости фотографии**: +X вправо, +Y вверх, +Z к камере. Центр — центр изображения. Единица длины — ширина *изображения*, а не метр реального мира. Для 3D-модели с геометрией в метрах и фото участка шириной условно 8 метров начальный масштаб около `0.125` (1/8), но для точной регистрации нужно учесть перспективу, высоту съёмки, физическое положение башни и начало координат 3D-модели. «На глаз» для большой постройки это может дать сильную ошибку.

## Ограничения

Это **image tracking**, не VPS и не трёхмерное определение положения относительно башни. Удерживание при ходьбе вокруг здания и точное совмещение всей архитектуры не гарантированы. При потере цели MindAR скрывает привязанный объект. Проверять обязательно с точки обзора, на которой будет стоять посетитель. Загрузка библиотеки и демонстрационной цели требует Интернета; можно позднее разместить библиотеки локально на хостинге.
