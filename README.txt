# Коррекция стыка стены с башней и непрозрачности

Версия исправления для действующей markerless v1.3.
**Алгоритм распознавания /track, motion.js и OpenCV API НЕ изменены.**

## Установка в локальный репозиторий

Скопируйте эти два файла в репозиторий с заменой:

- `server/track_refs/tower/wall-overlay.png` — готовая стена для текущего ракурса.
- `wall-lab/app.js` — правка редактора, чтобы последующий экспорт сохранял непрозрачную кладку и был доступен параметр **«Нахлёст стены на башню (px)»**.

GitHub Desktop: Commit -> Push origin. Если Render настроен на автодеплой из main,
дождитесь успешной сборки Render. Иначе запустите Deploy latest commit вручную.
**Именно Render отдаёт наложение из server/track_refs; одного GitHub Pages недостаточно.**

Проверяйте: https://xintes.github.io/webar-ruins/track/?api=https%3A%2F%2Fwebar-ruins.onrender.com

При старом изображении обновите страницу/очистите её кэш. В браузерном редакторе,
если ранее были сохранены пользовательские настройки, поле нахлёста появится
со стартовым значением 25 px. Убедитесь, что флажок «Башня перекрывает стену» включён.

Готовый PNG сделан под исходный кадр 1200×934, с зафиксированным краем башни.
Это 2D-подготовка наложения, НЕ метрический 3D-якорь. При сильном параллаксе
стык может потребовать дополнительной коррекции в режиме /wall-lab/.

Для реальных руин настройка должна использовать другую эталонную фотографию,
маску и новую 3D-геометрию; изменения демонстрационного PNG не дают универсальной точности.
