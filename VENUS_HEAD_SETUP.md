# WebAR — экспериментальная сцена `venus_head`

## Что изменено

- Добавлена **отдельная** обзорная зона `venus_head`; существующая `tower` сохранена.
- Из 10 предоставленных снимков подготовлены 10 PNG с настоящими пикселями скульптуры, вырезанными с исходных фотографий по маске. **Генерация/перерисовка скульптуры для OpenCV не использовалась.** У прозрачных вырезок могут быть небольшие погрешности по краю, особенно возле пьедестала.
- В `server/tracker.py` добавлено чтение альфа-канала эталонных PNG. SIFT/ORB ищет ключевые точки только внутри маски, а не по мебели и людям на фоне. Эталоны старого формата JPEG/PNG без прозрачности обрабатываются как прежде. Для всех активных ракурсов бюста и старой башни **заранее сохранены дескрипторы `.npz`**, чтобы уменьшить затраты при запуске Render.
- Для каждого ракурса добавлен прозрачный диагностический PNG с вручную заданными контрольными точками. На фронтальном виде это глаза, нос и рот; сбоку — видимый глаз, нос и рот; на верхних видах — отметка головы. **Это не отдельное обнаружение глаз/носа/рта**: координаты этих отметок переносятся по гомографии после распознавания объекта.
- В конфигурацию включены 7 из 10 ракурсов. Остальные 3 PNG сохранены в папке сцены для дальнейшей настройки. Это ограничивает число сравнений на бесплатном Render.

## Установка

1. Убедитесь, что в GitHub Desktop открыта ветка `main` репозитория `webar-ruins`.
2. Распакуйте архив **содержимым в корень** локального репозитория `C:\Users\Admin\Documents\GitHub\webar-ruins`, сохраняя папки `server` и `tests`, с заменой **только** двух изменённых файлов: `server/tracker.py` и `server/track_zones.json`. Новые файлы в `server/track_refs/venus_head/` и `tests/test_venus_scene.py` должны добавиться.
3. Посмотрите в GitHub Desktop, что `tower` в `server/track_zones.json` осталась, а `venus_head` добавилась.
4. Сделайте `Commit` → `Push origin`.
5. На Render для `webar-ruins` проверьте **Deploy succeeded** и Source = ваш новый коммит. Если нет автоматического развёртывания, выберите `Manual Deploy` → `Deploy latest commit`.
6. Откройте `https://webar-ruins.onrender.com/api/track/zones`. В JSON должна быть `venus_head` и 7 видов, а также старая `tower`.
7. Откройте сайт `https://xintes.github.io/webar-ruins/track/?api=https%3A%2F%2Fwebar-ruins.onrender.com` на телефоне. Обновите страницу и выберите зону **«Бюст — глаза, нос, рот (эксперимент)»**.
8. Направьте камеру на настоящий бюст, сначала почти фронтально. Для проверки на ПК можно использовать кнопку «Проверить фотографию» и **исходную** фотографию. После узнавания должны появиться контрольные подписи на лице.

## Ограничения и следующий этап

- **Это обучение посредством подготовленных эталонных признаков SIFT/ORB, а не тренировка нейросети.** Дескрипторы уже рассчитаны и сохранены в `.npz`, при старте загружаются в память. Если `.npz` отсутствует или повреждён, программа переходит к обычному извлечению признаков из эталонного PNG.
- Многовидовая гомография сопоставляет разные фото, но не создаёт единую метрическую 3D-карту. При ходьбе вокруг объёмного бюста 2D-метки могут смещаться из-за параллакса, даже при успешном распознавании.
- На обратной стороне у нас пока нет снимков с высоты лица; верхние снимки не заменяют горизонтальные виды со спины. Для полного обхода придётся дополнить эти ракурсы и перейти к устойчивой 3D-позе (PnP + 3D опорные точки / SfM или другой подходящий способ).
- **Веб-отображение произвольных GLB пока не добавлялось.** Отметки нужны, чтобы подтвердить распознавание и проверить закрепление перед заменой на настоящий объект.
- Когда проверите стабилизацию на живой камере, выберите точную целевую часть головы. Следующий этап: уточнить её позицию в 3D и привязать GLB один раз, а затем обновлять положение виртуальной камеры.
