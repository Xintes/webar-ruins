# WebAR /track — с чего начать

## Что было не так

- `/wall-lab/` — редактор геометрии. Кнопка камеры в нём показывает ручное наложение без распознавания.
- `/track/` — автоматический поиск башни через OpenCV на Python-сервере.
- GitHub Pages не исполняет Python. Страница `https://xintes.github.io/webar-ruins/track/` — лишь клиент: без HTTPS API она не сможет распознать башню.
- Адрес `http://localhost:8000/track/` доступен на компьютере, **только если** там запущен FastAPI (не `python -m http.server`).

## Проверка на ПК

1. Распаковать архив в отдельную папку, где видны `INSTALL_WINDOWS.bat`, `START_WINDOWS.bat`, `server/`, `track/`.
2. Запустить `INSTALL_WINDOWS.bat` (нужны Python 3.12 и доступ pip в интернет).
3. Запустить `START_WINDOWS.bat` и оставить консоль открытой.
4. Проверить `http://localhost:8000/api/track/zones`: должен вернуться JSON со списком зон `tower`.
5. Открыть `http://localhost:8000/track/` — появится сообщение `OpenCV API подключён`.
6. Нажать `Проверить фотографию`, выбрать `wall-lab/reference.png`: стена появится после успешного распознавания.
7. Для теста через веб-камеру открыть фото на другом экране и направить камеру на него. При уводе камеры стена должна исчезнуть.

## Для телефона

GitHub Pages можно оставить фронтендом, но нужно развернуть отдельный доступный по **HTTPS** Python API: серверный `server/` с `/api/track/zones`, `/api/track/frame`, `/api/track/assets/…`. В `/track/` открой `Подключение API на телефоне`, укажи адрес HTTPS API (без хвостового `/api`) и сохрани. При успешном соединении доступно распознавание.

**Не открывай сервер наружу без настройки безопасности.** Маршрут `/api/track/train` должен быть закрыт от посетителей, доступ ограничен и защищён HTTPS; на стороне FastAPI есть проверки, но полноценного лимита запросов в этом прототипе нет.

## Что именно представляет собой результат

Это гомография 2D-изображения, вычисленная по деталям башни. Она позволяет переносить заранее отрендеренную прозрачную стену в близком ракурсе. Это **не** полноценное позиционирование 3D-модели в координатах мира, а при отходе вбок от обзорной точки возможна ошибка параллакса. Для строгой 3D-привязки потребуется калибровка геометрии и `solvePnP`.
